## 🛠️ Local Development & Portal Maintenance

To preview or run the portal locally:

```bash
# Clone the repository
git clone https://github.com/vkamthe/vkamthe.github.io.git
cd vkamthe.github.io

# Open locally in your browser or run a simple static server
python3 -m http.server 8000
```
Then visit `http://localhost:8000/`.
